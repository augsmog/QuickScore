The candidate is now merged as main `a71939a`.

These checks prove the current code can exercise those flows with the flag explicitly enabled and disposable backend credentials. They do **not** prove the normal build works with the flag omitted/defaulted, that the effective EAS production auth values are configured, that the live Supabase project permits the flow, or that a physical fresh device completes guest join and scoring. The default flag remains off in code. Main SHA `a71939a` had no xdevice checks at the time of this review; its standard build, schema, tournament, iOS and M4b checks were still in progress, so this report does not claim those exact-main checks green.

G1 remains open.

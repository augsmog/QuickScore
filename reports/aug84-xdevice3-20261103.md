## Changes

- Existing `EXPO_PUBLIC_FEATURE_CROSS_DEVICE_SHARING` gates all handoff runtime behavior, sign-in preparation, UI, universal-link rewriting, and native association config. Real auth is also required for account imports.
- Email signup/sign-in and Apple/Google sign-in prepare guest handoff before replacing the session. Guest outbox drains under the original identity; unresolved entries block sign-in. No queued write is reassigned to a different actor.
- Approved online memberships transfer in place using a guest-created, hashed, expiring one-use capability. Claims pin a destination, check the signed caller, lock affected contests, and persist an idempotent receipt. No contest, round, player, score event or operation receipt is duplicated. Historical score attribution stays unchanged.
- Conflict rule: existing account membership wins, including pending/revoked memberships; replaced guest access is revoked. Pending requests remain pending, with existing account requests winning.
- Local-only guest contest/round snapshots import into private account history by stable local ID. Account's first complete saved scorecard wins duplicate IDs. Scores are never concatenated, and course/date/name are not identity keys. Failed uploads remain on-device and pin the destination; repeat imports do not duplicate rounds. Later local-only edits are not continuous cloud sync; live contests use the existing protocol.
- Account history hydrates before capture/restore and checks current identity before restoring data. Sign-out retains its existing contest reset; pending handoff keys are included in the account deletion inventory. New rows cascade on Auth user deletion.
- Handoff UI offers sign-in, in-progress status, success and retry. Anonymous guests can reach sign-in without the route guard redirecting them. Public `/r/` views omit the handoff panel.
- Universal links accept exact HTTPS origin plus `/r/<64 hex>` and `/join/<six-character code>` routes, with custom scheme support. Unexpected hosts/routes, embedded credentials and encoded separators fail closed. Query strings/fragments are discarded. Warm join route changes refresh the code field. PR #105's live URL/token flow is retained.
- Added flagged Expo iOS associated domains / Android verified intent filters, plus release association requirements in `scoresnap/docs/xdevice-step3.md`.
- All DB changes are confined to new migration `20261103071000_account_handoff.sql`. Includes private capability storage, guarded RPCs and RLS-protected history. No previous migration changed. Supabase CLI/server binaries were unavailable; migration was written against the checked-in schema without network or live access.
